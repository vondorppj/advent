# Advent Calendar · for my love 💌

Dépose **tous les fichiers de ce dossier** dans ton dépôt GitHub, puis :
*Settings → Pages → Deploy from a branch → `main` / `(root)` → Save*.

- Mot de passe : demandé une seule fois, ensuite le téléphone s'en souvient.
- Les textes et les photos sont chiffrés dans `data.json` : illisibles sans le mot de passe,
  même en ouvrant les fichiers du dépôt.
- Chaque case ne s'ouvre qu'à partir de son jour (heure du téléphone).
